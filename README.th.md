# 🪖 heltect

**AI-Powered Safety Helmet Detection**

[English](README.md) | [ภาษาไทย](README.th.md)

## ภาพรวมโครงการ (Overview)

**heltect** เป็นโครงงานระบบตรวจจับการสวมหมวกนิรภัยด้วยปัญญาประดิษฐ์ (AI) ที่พัฒนาขึ้นเพื่อสนับสนุนความปลอดภัยในพื้นที่ปฏิบัติงาน โดยประยุกต์ใช้เทคโนโลยี Computer Vision และ Object Detection

โครงการมุ่งเน้นการตรวจจับว่าผู้ปฏิบัติงานสวมหมวกนิรภัยหรือไม่ พร้อมศึกษาแนวทางการจำแนกสีหมวกและตรวจสอบความสอดคล้องกับข้อกำหนดของแต่ละพื้นที่ เพื่อช่วยตรวจพบการละเมิดข้อกำหนดด้านความปลอดภัยและแจ้งเตือนไปยังผู้รับผิดชอบ

## ความสามารถของระบบ (Features)

- **Helmet Detection** — ตรวจจับหมวกนิรภัยและระบุกรณีที่อาจไม่ปฏิบัติตามข้อกำหนดการสวมหมวก
- **Color Classification** — วิเคราะห์และจำแนกสีหมวกนิรภัยด้วยเทคนิคการประมวลผลภาพ
- **Zone Verification** — ตรวจสอบสีหมวกให้สอดคล้องกับข้อกำหนดด้านความปลอดภัยของพื้นที่
- **Alert Notification** — แจ้งเตือนเจ้าหน้าที่ผ่าน LINE เมื่อตรวจพบการละเมิดข้อกำหนด

*ความสามารถข้างต้นเป็นแนวทางการพัฒนาระบบ ซึ่งอาจปรับเปลี่ยนตามผลการทดลองและทดสอบ*

## หลักการทำงาน (How It Works)

ระบบมีแนวคิดการทำงาน 4 ขั้นตอนหลัก ได้แก่

1. **Detect** — ตรวจจับหมวกนิรภัยด้วยโมเดล AI
2. **Classify** — วิเคราะห์และจำแนกสีหมวกด้วย OpenCV
3. **Verify** — ตรวจสอบการสวมหมวกและสีหมวกตามข้อกำหนดของพื้นที่
4. **Alert** — ส่งการแจ้งเตือนผ่าน LINE เมื่อพบการละเมิดข้อกำหนดที่อาจเกิดขึ้น

## เป้าหมายโครงการ (Project Goals)

- ประยุกต์ใช้ AI และ Computer Vision เพื่อสนับสนุนความปลอดภัยในพื้นที่ปฏิบัติงาน
- พัฒนาและประเมินประสิทธิภาพโมเดลตรวจจับหมวกนิรภัย
- ศึกษาการจำแนกสีหมวกนิรภัยด้วย OpenCV
- ตรวจสอบการสวมหมวกและสีหมวกตามข้อกำหนดของแต่ละพื้นที่
- เชื่อมต่อผลการตรวจจับเข้ากับระบบแจ้งเตือนอัตโนมัติ
